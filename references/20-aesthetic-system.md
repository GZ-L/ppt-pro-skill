# 20 Aesthetic System

Use this reference when the user asks for PPT美化, 高级感, keynote-style, magazine style, Swiss grid, commercial polish, visual hierarchy, or when an existing deck looks crowded or plain.

When style-library references are available, use them only after reading `references/style-library/style-match-rules.md`. The style library can influence reusable visual traits, but it must not transfer page-specific content, logos, brands, people, product claims, or exact source compositions.

## Non-Negotiable Rules

- One slide, one message. The title should state the point, not only the topic.
- Visual hierarchy must be obvious within 3 seconds.
- Use fewer, stronger elements instead of many weak decorations.
- Align everything to a clear grid. Avoid accidental near-alignment.
- Leave real whitespace around the main idea.
- Use 1-2 typefaces or font roles. Avoid random font mixing.
- Use 2-3 core colors plus neutrals. Avoid rainbow palettes unless the brand requires them.
- Do not stretch images. Crop intentionally and preserve subject visibility.
- Make charts explain a point. Remove gridlines, redundant labels, and decorative effects when they do not help comprehension.
- Use motion only to reveal structure or pacing, not to decorate every object.

## Style Families

### Executive Swiss

Use for business reports, strategy, consulting, investor updates, research, and methodology decks.

- Tight grid, restrained colors, strong typography.
- Best for frameworks, comparisons, roadmaps, tables, and charts.
- Avoid decorative cards on every page.

### Editorial Keynote

Use for creator content, AI topics, conceptual explanations, and visual-first storytelling.

- Large title contrast, magazine-like cover, bold visual rhythm.
- Best for opening hooks, concept pages, workflow stories, and visual metaphors.
- Avoid turning every page into a poster; keep body pages usable.

### Apple Keynote

Use for product demos, launches, short talks, and highly focused narratives.

- One large statement or visual focus per page.
- Clean dark or light background, slow reveal, controlled pacing.
- Avoid too much small text.

### Technical Dashboard

Use for AI workflows, automation systems, product metrics, demos, and tool comparisons.

- Screenshots, pipeline diagrams, status chips, labels, and system maps.
- Use a restrained interface language.
- Avoid fake dashboard clutter.

### Creator Video Deck

Use when slides will become a video, screen recording, or social post.

- Each page must read in 2-4 seconds.
- Strong title, clear visual beat, zoom-safe layout, motion notes.
- Avoid dense paragraphs and tiny labels.

## Slide-Level Hierarchy

Each slide should define:

- Primary: the one thing the audience must notice first.
- Secondary: evidence, example, chart, screenshot, or framework.
- Tertiary: labels, source notes, supporting details.

Use size, weight, placement, color, and contrast to separate the levels. Do not rely on color alone.

## Layout Patterns

- Statement + evidence: large claim on one side, proof visual on the other.
- Before/after: split layout with equal visual weight and one highlighted difference.
- Three-part framework: three columns or stacked blocks with short labels.
- Process flow: left-to-right or top-to-bottom sequence, with 3-6 steps.
- Data story: headline insight, clean chart, one callout.
- Screenshot annotation: full screenshot with 2-4 callouts, no tiny paragraph labels.
- Cover: big title, specific subtitle, one strong visual signal, no crowded intro text.

## Typography

- Use title sizes only for true slide titles or hero statements.
- Keep body text short and scannable.
- Use consistent roles: title, section label, body, caption, number, source note.
- Avoid negative letter spacing and over-tight line height.
- For Chinese decks, prefer modern readable sans-serif fonts and avoid mixing too many weights.

## Color

- Start from the topic, audience, and brand constraints.
- Use one background system, one main text system, one accent system, and neutral dividers.
- Reserve accent color for key emphasis.
- Check contrast for body text, chart labels, and source notes.
- Avoid one-note palettes where everything is a variation of the same hue unless the brand requires it.

## Images And Screenshots

- Use images that reveal the actual product, workflow, person, place, or concept.
- Prefer fewer, larger visuals over many thumbnails.
- For screenshots, crop to the relevant interface area and add concise callouts.
- Do not blur or darken a visual so much that it cannot be inspected.
- Keep source notes when the image, chart, or quote comes from external material.

## Chart And Data Treatment

- Write the takeaway as the slide title.
- Highlight the key series or data point.
- Remove decorative shadows, 3D effects, and heavy borders.
- Use direct labels when possible.
- Keep axis and units readable.
- Put detailed methodology in speaker notes or appendix.

## Common Beautification Fixes

- Replace paragraph dumps with action title + 3 short evidence points.
- Convert lists into process, comparison, matrix, or timeline layouts.
- Increase spacing before adding decoration.
- Reduce colors before adding gradients.
- Replace generic icons with meaningful diagrams or screenshots.
- Standardize title placement, margins, and footer/source treatment.
- Create section pages when the story needs pacing.

## Director Taste Gate

Before production, reject style choices that create any of these problems:

- The reference mood is impressive but unrelated to the user's topic.
- Visual density hides the argument.
- The palette becomes one-note or over-saturated.
- Typography is decorative but unreadable.
- The slide looks like copied artwork instead of a new deck.
- The cover is strong but body pages have no usable system.
